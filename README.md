# OpenFrameTap Mosaico

**把 ESP-Mosaico 变成 DJI Osmo Pocket 3 的独立触摸遥控器。**

OpenFrameTap Mosaico 是一个运行在 **ESP-Mosaico V1.0 / ESP32-S31** 上的实验性相机控制固件。无需手机或 Linux 开发板作为运行主机，即可连接 Pocket 3，使用触摸摇杆、相对姿态头追和实体拍摄键，并查看相机状态与低帧率图像预览。

本项目源自 OpenFrameTap 的 ROCK 4D 实现，但采用独立的 ESP-IDF / FreeRTOS / LVGL 技术栈。**仅实现 Pocket 3 的常规模式：Mosaico 加入相机自己的 2.4 GHz 热点，不使用外部路由器或 RTMP 直播。**

> 当前是经过单套硬件实测的开发原型，不是 DJI 官方产品。仅 Pocket 3 已验证；不保证其他机型、固件版本或 Mosaico 修订版兼容。

## 已有功能

| 功能 | 当前实现与边界 |
| --- | --- |
| 无线连接 | BLE 扫描与设备选择、记忆上次选择、DJI 应用层会话、每次获取热点凭据、自动加入 Pocket 3 SoftAP、维护 UDP 会话 |
| 触摸摇杆 | yaw / pitch 两轴，离中心越远速度越快，径向线性偏移 32–188；松手停止，无固定两秒中断 |
| 云台动作 | 回中、180° 翻转，独立动作确认与冷却 |
| 头追 | 基于板载 IMU 的相对 yaw / pitch 跟随；长按启用、松开停止；不驱动 roll |
| 限位反馈 | 头追限位状态的橙色提示和短脉冲振动，离开限位后解除；属于当前实测范围内的检测 |
| 实体拍摄键 | Function Button 按相机当前模式拍照或开始录像；录像中再次短按停止并保存 |
| 相机规格 | 左侧双拨轮调整普通录像分辨率 / 帧率，以及照片画幅 / 文件格式；提供 Video / Photo 切换 |
| 数码变焦 | 右侧滑块，按当前 Pocket 3 模式和分辨率限制范围 |
| 图像预览 | 实际接收并软件解码 Pocket 3 的 H.264 图像，在 HEAD 模式中央显示；低帧率、非流畅视频 |
| 状态与电量 | BLE / Wi-Fi / 会话状态、Pocket 电量、Mosaico 电压及带估算标记的本机电量 |
| 触摸界面 | 深色大触摸区域、四边滑出的半透明径向菜单，尽量留出中央画面 |

### 预览不是高帧率图传

当前使用 OpenH264 **软件解码**，不是 ESP32-S31 的 H.264 硬件解码。通过限制解码负载、丢弃过时图像及有界刷新恢复，在小屏幕上显示真实连续更新的画面。

历史短窗口测量通常约 **1–2 fps**，复杂场景、无线状态与解码耗时都会影响更新率及延迟。这不是稳定帧率承诺，也不能替代低延迟 FPV。中央显示约 **352 × 198**；默认 JOYSTICK 模式隐藏预览，切换 HEAD 后显示，**无需按住头追才能看画面**。现有 FRESH 预览策略暂时冻结。

### 相机规格与变焦

- 普通 16:9 录像：1080p / 2.7K / 4K；24 / 25 / 30 / 48 / 50 / 60 fps。
- 当前机身未返回完整能力表时，界面使用明确标记的 Pocket 3 普通录像配置，不声称所有选项均由设备动态枚举。
- 照片：16:9 / 1:1；JPEG / JPEG+DNG。部分标签来自协议与规格对照；参数读回成功不等同于逐档拍摄文件验证。
- 录像变焦上限：1080p 4×、2.7K 3×、4K 2×。照片 16:9 上限 2×，1:1 禁用变焦。
- 录像过程中禁止格式 / 模式变更；实体键仍可停止录像。未提供慢动作、曝光调整或完整 DJI Mimo 设置替代。

## 如何操作

1. Pocket 3 开机，将无线频段设为 **2.4 GHz**。关闭 DJI Mimo 和其他相机客户端。
2. Mosaico 开机，在设备列表选择自己的 Pocket 3。以后尝试重新发现并连接上次选择的设备。
3. 如果相机要求确认，在相机本机完成；没有弹出确认不代表失败，已获准会话可直接继续。连接状态应以界面及协议响应为准。
4. 等待相机控制会话就绪，再操作摇杆、头追或拍摄键。

| 手势 / 按键 | 操作 |
| --- | --- |
| 从上边缘向内滑 | 打开 JOYSTICK / HEAD 模式菜单和摇杆区域 |
| 从下边缘向内滑 | 打开回中、180°、断开 / 扫描菜单 |
| 从左边缘向内滑 | 打开相机规格双拨轮 |
| 从右边缘向内滑 | 打开变焦滑块 |
| 点击菜单圆外 | 关闭菜单 |
| HEAD 模式、菜单全部关闭时，中央长按 1 秒 | 两次短振后启用相对头追；松手立即停止 |
| 短按 Function Button | 根据相机状态拍照 / 开始录像 / 停止录像 |

头追每次按下时重新建立相对参考；转动 Mosaico 控制相机 yaw / pitch，松开后停留在当前位置。四边保留给菜单手势。这里不是绝对磁航向系统，也不承诺无漂移、零跟随延迟或全机械范围的严格 1:1 映射。

## 硬件与开发环境

已验证硬件为 **ESP-Mosaico V1.0（ESP32-S31）** 和 **DJI Osmo Pocket 3**：

- 480 × 480 圆角 CO5300 屏幕及 CST9220 系列触摸（使用 CST9217 兼容驱动）。
- BMI270 六轴 IMU、两颗 BMM150 地磁传感器、振动马达与 Function Button。
- 16 MB PSRAM；USB CDC 日志与下载恢复。
- BQ27220 电量计；当前电池配置仅针对已确认的 **65 mAh** 电池。

开发使用 **ESP-IDF 6.1 的 esp32s31 preview target**，不是 esp32s3。依赖锁定于 `dependencies.lock`，OpenH264 固定为子模块提交。不要通过升级 SDK 或替换芯片目标来绕过编译错误。

克隆后先初始化依赖子模块：

```sh
git submodule update --init --recursive
```

Windows / PowerShell、已安装匹配 EIM 环境时：

```powershell
./scripts/mosaico.ps1 configure
./scripts/mosaico.ps1 build
```

首次烧录前必须核对芯片、串口和现有分区。当前脚本是**应用分区烧录**，不是任意新板的一键全量安装器。具体操作、SDK 路径和恢复说明见 [构建与烧录](docs/build.md)。

## 电量说明

右上角为 Pocket 电量，左上角为 Mosaico 本机电量 / 电压。**M~ 表示估算值**：当前 65 mAh 电池的可回滚 RAM 配置已完成读回与充电观察，但尚无修正后完整放电精度验证。

不要把该电量计配置应用到其他容量的电池。普通使用不需要执行电量计诊断或修正命令；不要改写 OTP、改变充电硬件或强制深度放电。

## 架构

```text
LVGL UI / Function Button / IMU
              ↓ 有界输入与状态快照
     控制安全逻辑 / Pocket 3 profile
              ↓
BLE 会话及凭据 → Wi-Fi STA → 单 UDP writer / ACK / 保活
                                   ├─ 状态与控制
                                   └─ 媒体接收 → OpenH264 → 小屏预览
```

DUML / CRC / 重组 / 命令编码与 GUI 分离；UI 不直接写无线协议。控制、触摸采样与保活不依赖视频解码完成。

目录说明：

- `firmware/esp_mosaico/main/`：板级驱动、连接、状态、UI、视频和任务调度。
- `firmware/esp_mosaico/components/oft_protocol/`：DUML、UDP、相机 profile、控制与板端测试。
- `firmware/esp_mosaico/components/oft_openh264/`：固定版本解码器及 ESP 适配。
- `firmware/esp_mosaico/components/oft_sensors/`：传感器适配依赖。
- `scripts/mosaico*`：受限构建、串口记录和开发诊断工具。
- `docs/`：构建、验证边界和维护说明。

独立仓库不包含原项目的 Linux / BlueZ / GTK / RTMP 实现，也不需要 ROCK 4D 运行环境。

## 安全与已知限制

- 松手、触摸取消、输入过期和断开触发停止；控制输入 watchdog 为 250 ms。
- 无线已经失效时，**无法保证停止包送达或云台物理归零**。首次操作请留出云台运动空间，不用于安全关键场景。
- 相机动作经过类型与状态检查；不开放任意命令发送，不使用 raw PWM、相机校准、固件升级或清除配对流程。
- 热点密码仅供当前会话使用，不保存到项目日志或持久配置。私有抓包、设备日志与构建产物不纳入 Git。
- 当前参考配对身份沿用开发阶段 profile；全新设备首次确认流程尚未取得与已配对重连同等覆盖，不是生产级独立设备身份方案。
- 只有 Pocket 3 获得实机验证；不支持 Pocket 4 / 4P、外部路由器直播、RTMP、触摸对焦或高帧率视频。
- 板载双地磁传感器不等于经过校准的绝对头追；本机电量不等于精密容量计。

最近继承的固件验收记录为 **78 项板端测试通过**，并有实际连接、四向摇杆、松手停止、回中 / 翻转、实体拍摄及设置读回证据。拆分仓库本身不产生新的硬件验收结论。详见 [验证与维护](docs/development.md)。
